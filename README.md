# Subtitle AI Translator V7 — Plain Word Output

این نسخه برای ترجمه متن PDFهای فنی به فارسی و ساخت یک فایل Word ساده از ابتدا ساخته شده است. منطق ارائه‌دهنده‌ها، واژه‌نامه و توابع ترجمه از پروژه قبلی نگه داشته شده‌اند؛ تغییر اصلی در استخراج متن و تولید فایل Word است.

## خروجی چه شکلی است؟

- یک پاراگراف Word برای هر بلوک متنی استخراج‌شده از PDF؛ شکست خط‌های معمول داخل پاراگراف تا حد ممکن به فاصله تبدیل می‌شود.
- هیچ تصویر، لوگو، نمودار، سربرگ، پابرگ، شماره صفحه یا قالب‌بندی منبع وارد Word نمی‌شود.
- متن خروجی قابل ویرایش است؛ جدول‌ها به‌صورت جدول بازسازی نمی‌شوند و ممکن است محتوایشان به شکل پاراگراف/بلوک‌های متنی ساده استخراج شود.
- متن تکراری واقع در حاشیه بالا/پایین صفحات و شماره‌های مستقل صفحه حذف می‌شوند.
- اعداد و شناسه‌های فنی با محافظت موجود در منطق ترجمه نگه داشته می‌شوند؛ با این حال همیشه خروجی فنی را بازبینی کنید.
- PDF اسکن‌شده که متن قابل انتخاب ندارد، در این نسخه OCR نمی‌شود.

## نصب در Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
copy config.example.json config.json
```

کلید WinkAPI را مانند نسخه قبلی در متغیر محیطی `WINKAPI_API_KEY` قرار دهید و تنظیمات مدل را در `config.json` بررسی کنید. تنظیمات provider/model همان ساختار نسخه قبلی را دارد.

## ابتدا استخراج را بدون API آزمایش کنید

```powershell
python translate_document.py "datasheet.pdf" --dry-run
```

این دستور تعداد پاراگراف‌ها را نشان می‌دهد و چند پاراگراف اول را در ترمینال چاپ می‌کند.

## ترجمه PDF به Word

```powershell
python translate_document.py "datasheet.pdf" -o "datasheet_fa.docx"
```

ادامه از checkpoint ذخیره‌شده:

```powershell
python translate_document.py "datasheet.pdf" -o "datasheet_fa.docx" --resume
```

ورودی DOCX نیز پشتیبانی می‌شود، اما فقط پاراگراف‌های اصلی خوانده می‌شوند؛ جدول‌ها، تصاویر و سربرگ/پابرگ آن وارد خروجی نمی‌شوند.

## نکته مهم درباره استخراج

این نسخه مستقیماً از متن PDF با PyMuPDF استفاده می‌کند و دیگر PDF را با `pdf2docx` تبدیل نمی‌کند. ترتیب متن در فایل‌های چندستونه یا PDFهایی با چیدمان پیچیده ممکن است کامل نباشد؛ قبل از ترجمه اصلی، `--dry-run` را اجرا کنید و ترتیب پاراگراف‌ها را بررسی کنید.
